Redes Neuronales Básicas
Implementación de redes neuronales básicas utilizando Python y NumPy.


 Descripción

Este repositorio contiene la implementación de una práctica introductoria
de Machine Learning y Deep Learning utilizando Python y NumPy.

  Contenido

- Operaciones matemáticas con NumPy.
- Implementación de un perceptrón.
- Red neuronal de una capa.
- Red neuronal multicapa.
- Propagación hacia adelante.
- Retropropagación (Backpropagation).
- Entrenamiento de una red neuronal para resolver XOR.

  Tecnologías utilizadas

- Python
- NumPy
- Google Colab
